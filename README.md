# 📦 資材・保管場所検索アプリ (AI搭載✨)

社内や倉庫にある資材や備品が「どこにあるのか」を一瞬で探せる検索アプリです。  
資材の正確な名前を知らなくても、「掃除で使うもの」「害虫対策」といった**大まかな使用用途を入力するだけ**で、該当する資材の場所と図面をパッと表示してくれます。

## 💡 どんなアプリ？（主な機能）

1. **言葉で検索（直接検索）**
   * 「雑巾」や「段ボール」などの名前を入れると、保管場所・詳細位置・図面番号をすぐに表示します。
2. **あいまい用途検索（AI検索）**
   * 「掃除道具」や「ゴキブリ対策」といった使い道を入力すると、AIが推測して「どの資材を使うべきか」を選び出し、その場所を教えてくれます。
3. **図面（マップ）の横並び表示**
   * 検索結果の表のすぐ隣に保管場所の図面を表示。文字と図面を同時に確認できるため、迷わず目的の場所へ取りに行けます。

## ✨ このアプリのこだわり・オリジナリティ（独自ポイント）

一般的な検索ツールにはない、AI技術と使いやすさを追求した**3つのオリジナル機能**を組み込んでいます。

1. **名前が分からなくても探せる「AI用途検索」**
   * 従来の検索システムは「正確な資材名」を入力しないとヒットしませんでしたが、このアプリはAI（Google Gemini API）を活用し、「何に使いたいか（使用用途）」から必要な資材をAIが自動で判断して提案します。
2. **無料枠を超えないための「かしこい節約検索」の仕組み**
   * AI（Gemini API）の利用制限にかからないよう、プログラムに工夫をしました。「直接の名前検索」でヒットした場合はAIを使わずに一瞬で結果を返し、名前で見つからない場合のみAIを呼び出す「2段階検索」を自作して組み込んでいます。
3. **スクロール不要な「表とマップの横並び」画面設計**
   * 検索結果の件数が多くなってもマップが下へ追いやられないよう、画面を左右に分割（左：検索結果の表、右：保管場所の図面）し、直感的に場所が把握できるレイアウトを実現しました。

## 🛠️ 使っている技術・サービス（分かりやすい解説）

* **Streamlit（ストリームリット）**: アプリの画面や検索の仕組みを作るための道具
* **Python（パイソン）**: アプリを動かすためのプログラム言語
* **Google Gemini API (`gemini-3-flash-preview`)**: 資材の用途を推測するかしこいAI
* **GitHub（ギットハブ）**: アプリのプログラムや画像を保存しておくインターネット上の倉庫
* **Streamlit Community Cloud**: 作成したアプリをWeb上に公開して誰でも使えるようにするサービス

## 🔄 データ（資材一覧）の更新方法

資材の場所や在庫数が変わったときは、以下の簡単な手順でアプリのデータを最新に更新できます。

1. 元のスプレッドシートを更新後、CSV形式（`inventory_data.csv`）でパソコンに保存します。
2. GitHubにある同名のファイルへ新しいファイルを上書き保存（Commit）します。
3. 数分後、アプリ側のデータが自動的に最新情報へ切り替わります。
