# 📦 資材・保管場所検索アプリ (AI搭載✨)

社内の資材や備品が「どこにあるか」を、名前や使用用途から一瞬で検索できるアプリです。

## 🌟 主な機能

1. **キーワード検索（直接検索）**
   * 「雑巾」や「段ボール」などの資材名を入力すると、保管場所・詳細位置・図面番号をすぐに表示します。
   * **節約機能付き**：名前で直接見つかった場合はAIを使わないため、APIの無料利用枠をムダ遣いしません。

2. **AI用途検索（Gemini API搭載）**
   * 「掃除道具」や「ゴキブリ対策」といった**使用用途**で検索すると、AI（Gemini）が関連する資材を推測して自動で抽出します。

3. **マップ（図面）の横並び表示**
   * 検索結果の表のすぐ横に保管場所の図面を表示し、どこに取りに行けばいいかが一目で分かるレイアウトにしています。

---

## 📁 ファイル構成

このアプリは以下の4つのファイルで動いています。

* `app.py` : アプリの画面や検索処理を行うメインプログラム
* `inventory_data.csv` : スプレッドシートからダウンロードした資材データ
* `map_image.png` : 保管場所（図面）の画像ファイル
* `requirements.txt` : アプリに必要な道具（ライブラリ）の一覧

---

## 🔄 データの更新手順（資材や場所が変わったとき）

資材の場所や在庫数が変わったときは、以下の手順でアプリのデータを更新できます。

1. 元のスプレッドシートを開きます。
2. メニューの **「ファイル」＞「ダウンロード」＞「カンマ区切り形式 (.csv)」** を選択します。
3. ダウンロードしたファイルの名前を `inventory_data.csv` に変更します。
4. GitHubの画面を開き、古い `inventory_data.csv` を新しいファイルで上書き保存（Commit changes）します。
5. 数分後、アプリに最新データが反映されます。
